# 南湖搭子

适配手机的中南财经政法大学校园拼单原型。页面可以在本机演示；要让不同访问者看到同一份内容，需要 Supabase 项目。

## 启用共享数据

1. 在 Supabase 创建项目。
2. 打开 SQL Editor，运行 `supabase/schema.sql`。
3. 将项目 URL 和 publishable key（旧项目可用 anon key）填入 `supabase-config.js`。
4. 用静态网站托管 `index.html`、`app.js`、`supabase-config.js`。

共享模式中，所有访问者读到同一份拼单列表；发布与报名会写入数据库；“我的”根据输入的 20 开头的 12 位学号查询。

## 关于 12 位用户名

入口只检查学号是否为 20 开头的 12 位数字；这不是学校身份验证。任何人都能输入任意符合格式的数字或冒用别人的学号，所以不能把“我的”当成可靠的账号隐私边界。联系方式在点击参加后返回，但用户名可伪装，无法保证只有真实参加者查看。请勿收集或发布手机号、学号之外的敏感信息；正式使用前应增加密码或学校身份认证，再收紧数据库策略。

SQL 通过 RLS 禁止客户端直接写表，并用数据库函数检查用户名格式、人数和拼单操作。publishable/anon key 可以放在浏览器；不要把 `service_role` 或 secret key 放进前端或 GitHub。

未配置 Supabase 时，页面进入本机演示模式，示例和发布内容不会与其他设备共享。
